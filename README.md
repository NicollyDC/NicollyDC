## 🚀 Featured Projects

### 📦 [Proj-Estoque](https://github.com/NicollyDC/Proj-Estoque) — Desktop Inventory System

Manages products, stock movements, and costs, with stock entries created automatically from Brazilian electronic invoices (NF-e).

- **Problem:** manual stock entry is slow and error-prone.
- **Solution:** parses and validates NF-e XML files, then updates stock, unit conversions, and costs.
- **Stack:** Python, Tkinter, SQLite

`Python` `Tkinter` `SQLite` `XML` `Business Automation`

### 🚚 [Delivery-Sim-Distribuido](https://github.com/NicollyDC/Delivery-Sim-Distribu-do) — Distributed Delivery Simulation

A microservices-based simulation of delivery workflows, used to explore service communication and distributed architecture.

- Services communicate through **gRPC**.
- Environments are containerized with **Docker**.
- Uses **Monte Carlo simulation** to model delivery scenarios.

`Microservices` `gRPC` `Docker` `Simulation`

### 🛡️ [LogSec](https://github.com/NicollyDC/LogSec) — Security Log Monitoring

Processes security logs to flag potentially suspicious activity.

- Parses and analyzes log events.
- Identifies anomalies in access and event patterns.

`Python` `Log Analysis` `Cybersecurity` `Data Processing`
