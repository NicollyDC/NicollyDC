## Featured Projects

### Proj-Estoque
**Desktop inventory system: a full workflow from invoice to stock.**

Manages products, stock movements, and costs, creating stock entries from Brazilian electronic invoices (NF-e).

- **Problem:** manual stock entry is slow and error-prone.
- **Solution:** parses and validates NF-e XML files, then updates stock, unit conversions, and costs automatically.
- Local persistence with SQLite and a Tkinter desktop interface.

`Python` `Tkinter` `SQLite` `XML` `Business Automation`

[View repository →](https://github.com/NicollyDC/Proj-Estoque)
